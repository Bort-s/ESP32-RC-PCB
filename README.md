# ESP32 RC PCB
A versatile, compact ESP32 PCB designed for controlling two DC motors to build an RC car. Compatible with most Bluetooth controllers, including PS5, Xbox, Nintendo and custom apps

![Final preview](https://cdn.hackclub.com/01a12a2b-2189-7d51-ab53-d89246f021a9/Final%20Preview.png)

## Features
* Bluetooth Classic + Low Energy (BLE)
* Dual DC motor control
* Servo connector
* RGB LED

## Pinout
| ESP32 PIN | Component Pin |
| :---: | :---: |
| 14 | PWMA |
| 27 | AIN2 |
| 26 | AIN1 |
| 25 | BIN1 |
| 33 | BIN2 |
| 32 | PWMB |
| 13 | Servo |
| 16 | LED RGB |
| 22 | Programable button |

## Battery compatibility
The PCB supports batteries in the 6V–12V range.

Examples
* 2S LiPo Battery (strongly recommended)
* Rectangular 9V battery
* 6 alkaline 1.5V batteries

## Motor compatibility
The PCB is compatible with any motor with the following requirements:
* Brushed DC motor
* Max 1.0 A no-load current (per motor)
* Max 2.0 A Stall Current (per motor)

Examples
* N20/30/50 Motors
* TT Motors
* 130/180 Motors

## Servo compatibility
Small versions like SG90
